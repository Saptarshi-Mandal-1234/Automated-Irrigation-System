# Libraries required — ESP32 BLE Irrigation Firmware

Install these via Arduino IDE (Sketch > Include Library > Manage Libraries)
or let PlatformIO install them automatically from platformio.ini.

| Library                     | Version | Install name (Arduino Library Manager) |
|------------------------------|---------|------------------------------------------|
| ESP32 BLE Arduino            | bundled | Included automatically with the ESP32 board package (espressif/arduino-esp32) — no separate install needed |
| ArduinoJson                  | ^6.21.3 | "ArduinoJson" by Benoit Blanchon |
| DHT sensor library           | ^1.4.4  | "DHT sensor library" by Adafruit |
| Adafruit Unified Sensor      | ^1.1.9  | "Adafruit Unified Sensor" by Adafruit |

## Board package (Arduino IDE)

1. File > Preferences > Additional Board Manager URLs, add:
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
2. Tools > Board > Boards Manager > search "esp32" > install "esp32 by Espressif Systems"
3. Tools > Board > select your exact ESP32 dev board model
